# Recruiter Portfolio — V4

Premium React + TypeScript + Tailwind + GSAP portfolio for recruiter review.

## Implemented
- Interactive project index adapted from the supplied portfolio component
- GSAP hover/background transitions and idle motion
- ScrambleTextPlugin registration
- Project image preloading
- Live IST clock
- Project case-study modal
- Recruiter snapshot / proof section
- Engineering toolkit
- Responsive layout
- Resume CTA at `/resume.pdf`
- Accessible labels on interactive controls

## Before deployment
1. Put your real `resume.pdf` in `public/`.
2. Replace the `#` GitHub and LinkedIn links in `src/Portfolio.tsx`.
3. Add real GitHub/demo URLs to the `projects` array.
4. Replace any project description that does not exactly match your final project implementation.
5. Run `npm install && npm run build`.
6. Deploy the generated `dist/` directory.

The design intentionally keeps the supplied component's interaction language while changing its music-specific data model into a software-engineering portfolio.
